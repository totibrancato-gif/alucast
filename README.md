# Presupuestos Alucast

App de presupuestos de aberturas de aluminio (Probba, Serie 25, Mampara).

**Abrir la app:** https://totibrancato-gif.github.io/alucast/

Se puede instalar en la compu o el celular desde el navegador ("Instalar app" / "Agregar a inicio")
y funciona sin internet. Los presupuestos se guardan en cada dispositivo; para pasarlos de uno a otro
se usa la pestaña "Copia".

El dólar común del BROU se actualiza solo de lunes a viernes (`.github/workflows/dolar.yml`,
datos de la API pública de cambio-uruguay.com).
